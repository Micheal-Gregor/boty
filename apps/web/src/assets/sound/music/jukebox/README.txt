JUKEBOX — background music queue
================================

Drop song files here (.mp3, .ogg, .m4a, or .wav). Any number — 10, 50, whatever.

How it plays:
  • When a season starts, that season's theme (spring.mp3 / summer.mp3 / fall.mp3 /
    winter.mp3, one folder up) plays ONCE.
  • After the theme finishes, the songs in THIS folder shuffle and play one after
    another. When the queue runs out, it reshuffles. It keeps going until the season
    changes — then the next season's theme plays, and the jukebox shuffles again.

No code change needed — files here are discovered automatically at build time.
Filenames don't matter (the order is shuffled), so name them however you like.

Respect the player's controls: Music on/off, the volume slider, and the mute button
all apply to jukebox songs just like the themes.
